Términos de uso de Racha

Borrador para revisión legal. Este documento no ha sido revisado por un abogado.

Última actualización: 2026-11-10.

1. Aceptación

Al usar Racha (racha.gg), una aplicación gratuita de escritorio para Windows, aceptas estos términos. Si no estás de acuerdo, no uses la aplicación.

2. Qué es Racha

Racha analiza tus propias partidas de League of Legends para mostrarte qué te hace perder y qué cuidar en cada partida: récord contra rivales, win rate, reglas por partida, builds y errores repetidos.

3. Uso aceptable

Puedes usar Racha para tu juego personal. No la uses para:

  • Automatizar el cliente o el juego, ni para obtener ventajas que Riot prohíba.
  • Modificar, descompilar o redistribuir la aplicación de forma engañosa.
  • Abusar de la Riot API o de los servicios de Racha.
  • Violar los términos de Riot Games o la ley aplicable.

4. Sin garantía de subir de rango

Racha te muestra análisis basados en tus partidas. No garantiza que subas de rango ni resultados concretos: el resultado de cada partida depende de ti y de factores fuera del control de Racha.

5. La app solo lee datos del cliente

Racha solo lee la información que el propio cliente de League of Legends ofrece a las aplicaciones (League Client API y Live Client Data API, ambas de solo lectura) y la Riot API. No pickea, no banea, no acepta partidas y no modifica el juego por ti.
